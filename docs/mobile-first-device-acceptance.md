# HomeFlow 手机优先体验：真机验收清单

更新：2026-11-10 · 涵盖今日、计划、时光轴、家庭、管理五个页面

本文件列出在自动化测试、类型检查、构建和 Preview/Production 健康检查之外，**仍必须由实际 iPhone/iPad 操作验证**的体验。不要用测试通过推断所有手势在真机上正常。

## 通用（iPhone 竖屏 / iPad 横竖屏）

- [ ] 页面底部导航可以单手点击，切换标签后无横向滚动、卡片截断或无故跳顶
- [ ] 多个底部面板嵌套（例如“编辑计划 → 选择处理人”）时，最新面板始终在上层；背景不能点到
- [ ] 下拉框点击后从底部弹出；选项较多显示搜索；日文、中文和数字可检索；选择后不会重复保存
- [ ] 连续打开、关闭弹窗后仍保持页面原滚动位置；取消不会修改数据
- [ ] 输入时键盘不遮住保存按钮，键盘关闭后弹窗高度与滚动正常；数字和日期出现适合输入的键盘/系统控件
- [ ] 按钮、图标和分页不易误触；长文案在窄屏不截断；屏幕旋转后仍可点击

## 今日、任务和计划

- [ ] 今日列表分类切换、任务完成、跳过、延期与“查看计划”跳转工作正常
- [ ] 左滑展开操作后不会误点到其他行；取消跳过不写入记录
- [ ] 新增/编辑一次性、周期、购物、旅行计划时，连续选择成员、可见范围、年月不丢表单内容
- [ ] 历史年份、月份、状态可独立选择，包括“全部年份”“全年”，分页仍保留筛选
- [ ] 旅行结束时仍允许未勾完行程；超过 30 天的旅行会出现第二次明确确认；取消不结算积分

## 家庭、积分和管理

- [ ] 家庭积分历史切换年/月/成员/分类、商城兑换数量增减与抽奖操作流畅
- [ ] 奖励兑换、出资、取消合力兑换、核销奖励、下架等确认从底部弹出；成功提示不阻断操作
- [ ] 家庭成员与宠物护理新增/编辑/删除、重要日子的归档与恢复操作正常
- [ ] 通知已读、提醒设置和安静时间选择正常，返回之后列表位置保留
- [ ] 备份恢复确认能够取消；点击确认后才真正导入；不额外将 R2 图片储存到手机

## 时光轴与图片

- [ ] 进入时光轴、点击上传图标但未选照片时列表不刷新
- [ ] 照片分页、按需查看与放大正常；全屏图片支持“放大/还原”、双击切换和双指缩放及拖动，不触发整页放大
- [ ] 照片全屏删除确认显示在图片上方；取消不删除；确认后查看器正常关闭

## 自动化保障

- 本地源代码统一使用触控底部确认面板，无遗留浏览器原生阻断式确认窗口
- 编辑弹层做了滚动锁定、焦点恢复、背景 inert/aria-hidden、Photos 全屏层级隔离
- iPhone 和 iPad 的触控组件以至少 44px 为目标；常见业务行为有静态/单元回归测试
- 代码无额外的 D1/R2 查询、Cron、持久化缓存或本地照片写入

若真机发现问题，优先记录：**页面 → 操作步骤 → 预期 → 实际表现 → iPhone/iPad 型号与系统版本**，附截图或屏幕录像更容易定位。
