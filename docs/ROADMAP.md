# HomeFlow 完整功能开发路线

HomeFlow 产品流程：心愿 → 计划 → 执行 → 完成 → 回忆。

| 迭代 | 交付模块 | 核心验收 |
| --- | --- | --- |
| 0 | 私有 GitHub、Cloudflare Worker、隔离 D1、Vue/PWA、CI | 环境独立、生产 Preview 保护、个人 API 401、构建通过 |
| 1 | 家庭、个人账户、资料、豆沙与基本任务 | 单独登录、私人可见权限、归属与操作审计 |
| 2 | 重复任务、生日纪念日与统一提醒 | 每日、每周、工作日、跨月、实际完成日周期、提醒去重 |
| 3 | 心愿、旅行、行程、行李及 ChatGPT 计划导入 | HomeFlow Trip v1 JSON Schema、预览、合并及幂等 |
| 4 | 家庭/个人相册、时光轴与豆沙成长 | 私有照片权限、日期与成员过滤、数据导出 |
| 5 | 共享购物、储蓄目标、家計簿安全关联 | 不重复记账、只读取有授权的交易摘要 |
| 6 | 数据备份恢复、免费额度优化、双端验收 | iPhone/iPad、R2 限额、D1 查询消耗与离线恢复 |

数据处理原则：家庭共享不等于所有个人任务公开；豆沙是宠物家庭成员而不是账号；财务数据以家計簿为真实账本；所有业务记录必须可备份并保留历史。
