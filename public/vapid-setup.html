⌂ HomeFlow

只用 iPhone
开启推送提醒

无需电脑、终端或第三方密钥网站。VAPID 密钥直接在当前 Safari 浏览器中生成，不会发送给 HomeFlow 服务器。

① 在手机上生成密钥

只需要生成一次。两项密钥必须来自同一次生成，否则通知无法正常送达。

② 复制并分别保存到 Cloudflare

安全提醒：不要截图、上传、发到聊天或提交 GitHub。两个值都作为 Cloudflare Worker 加密 Secret 保存。配置完成后，点击下方清除。

③ 用 iPhone 设置 Cloudflare

  1. 保持这个页面，另开一个 Safari 标签访问 Cloudflare Dashboard。
  2. 进入 Workers & Pages → homeflow → Settings → Variables and Secrets。
  3. 添加 VAPID_PUBLIC_KEY，类型选择 Secret（加密），粘贴公钥并保存。
  4. 添加 VAPID_PRIVATE_JWK，类型同样选择 Secret（加密），粘贴完整的 JSON 私钥并保存。
  5. 回到 HomeFlow，刷新页面，再点击 开启锁屏通知。
打开 Cloudflare Dashboard ↗

④ iPhone 通知授权

iPhone 必须从 Safari 的分享菜单选择 添加到主屏幕，然后从桌面图标打开 HomeFlow 才能允许 Web Push；普通 Safari 标签可能无法订阅。

日本时间每天 08:00 执行提醒检查。配置密钥不代表已经成功收到通知，首次送达还需真机验证。

本页面不读取账号、数据库或 Cloudflare Token；密钥只存在于浏览器内存中，关闭页面或刷新后会消失。
